#+TITLE: vtx

libvtx and vtx live in this one repo.

*libvtx* is a VT100-and-extensions terminal emulator. It parses what a
program writes to a pty and keeps a grid of cells and faces. It turns a key
event into the bytes a real terminal would send. It doesn't open a pty, read
a keyboard, or draw anything, and it doesn't know what uses it. Package is
=libvtx=, nicknamed =vt=.

*vtx* is a terminal emulator and multiplexer built on top of libvtx. It
opens the pty, spawns the shell, reads the keyboard, draws the screen, and
holds several sessions and panes behind one server so a client can attach,
detach, and come back.

** Building

Guix is what this develops against:

#+begin_src sh
make test        # the whole suite
make test-term   # libvtx alone, with nothing else loaded
make vtx         # the binary
#+end_src

On a Mac, or a Linux box without Guix, put =FOREIGN=1= in front of any of
those and it uses whatever SBCL is already on the machine:

#+begin_src sh
make FOREIGN=1 test
#+end_src

libvtx has no dependencies. vtx needs only what SBCL already ships
(=sb-posix=, =sb-bsd-sockets=) and FiveAM to run its own tests.

** Getting it

libvtx is an ASDF system. Get it with [[https://ocicl.github.io/][ocicl]]:

#+begin_src sh
ocicl install libvtx
#+end_src

vtx is a program, not a library, so ocicl doesn't apply to it. On Linux or a
Mac, cloning this and building it is the straightforward way:

#+begin_src sh
make FOREIGN=1 install            # PREFIX defaults to /usr/local
make FOREIGN=1 install PREFIX=$HOME/.local   # if that's already on PATH
#+end_src

Or, if you already have one of these:

#+begin_src sh
ros install bretfhorne/vtx     # roswell
brew install bretfhorne/vtx/vtx    # homebrew
guix install vtx                    # guix, once this channel is added
#+end_src

A tagged release also carries a Linux AppImage and a macOS tarball.
